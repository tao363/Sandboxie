## 🔬 技术亮点

### 1. 内存池设计
```
创新点：
- 分离满页面和可用页面（减少搜索时间）
- 估计空闲单元格数（避免频繁扫描）
- 位图快速操作（8单元格批处理）
- 大块直接分配（避免管理开销）
```

### 2. 跨平台兼容
```
支持环境：
- 内核态 / 用户态
- x86 / x64 / ARM / ARM64
- Windows XP ~ Windows 11
```

### 3. 线程安全
```
机制：
- 内核态：ERESOURCE + IRQL
- 用户态：CRITICAL_SECTION + 递归支持
- 原子操作：InterlockedXxx
```
