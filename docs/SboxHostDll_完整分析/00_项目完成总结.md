## 🎯 核心内容

### SboxHostDll 模块简介

**定义**: 专门为 Microsoft Office ClickToRun 设计的 Sandboxie 兼容性 DLL 模块

**作用**: 通过 Hook OpenProcessToken API，为沙箱中的 Office 进程提供有效的访问令牌

**技术**: DLL注入 + API Hook + 令牌替换

### 工作流程

```
OfficeClickToRun.exe 启动
    ↓
Sandboxie 注入 SboxHostDll.dll
    ↓
DllMain 验证进程名称
    ↓
InjectDllMain 初始化 Hook
    ↓
InitHook 设置 OpenProcessToken Hook
    ↓
应用程序调用 OpenProcessToken
    ↓
SboxHostDll_OpenProcessToken 拦截
    ↓
检查是否为特殊账户令牌
    ↓
在主机进程中查找匹配令牌
    ↓
通过登录会话 SID 匹配
    ↓
替换并返回有效令牌
```

### 关键技术

1. **DLL 注入** - Sandboxie 自动注入机制
2. **API Hook** - SBIEDLL_HOOK 宏
3. **进程验证** - 只在 OfficeClickToRun.exe 中激活
4. **令牌分析** - ATL CAccessToken 类
5. **SID 识别** - S-1-5-7 和 S-1-5-100-*
6. **会话匹配** - 登录会话 SID 比较
7. **令牌替换** - 主机令牌替换沙箱令牌
