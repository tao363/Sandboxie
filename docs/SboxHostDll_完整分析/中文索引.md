## 💡 核心知识点速查

### 关键概念

| 概念 | 说明 | 详见文档 |
|------|------|----------|
| **DLL 注入** | Sandboxie 将 DLL 注入到目标进程 | 01, 03 |
| **API Hook** | 拦截 OpenProcessToken 调用 | 03 |
| **访问令牌** | Windows 安全上下文 | 04 |
| **SID** | 安全标识符 | 04 |
| **虚拟账户** | S-1-5-100-* 类型的服务账户 | 01, 04 |
| **登录会话 SID** | 用于匹配令牌的关键标识 | 04 |

### 关键函数

| 函数 | 作用 | 详见文档 |
|------|------|----------|
| `DllMain` | DLL 入口点，验证进程 | 03 |
| `InjectDllMain` | 注入初始化入口 | 03 |
| `InitHook` | 设置 API Hook | 03 |
| `SboxHostDll_OpenProcessToken` | Hook 函数，令牌替换 | 04 |

### 关键 SID

| SID | 名称 | 说明 | 详见文档 |
|-----|------|------|----------|
| `S-1-5-7` | ANONYMOUS LOGON | 匿名登录 | 04 |
| `S-1-5-100-*` | Virtual Account | 虚拟账户 | 04 |
| `S-1-5-5-X-Y` | Logon SID | 登录会话 | 04 |
