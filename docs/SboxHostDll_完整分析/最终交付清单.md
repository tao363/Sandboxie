## 💡 核心内容概览

### SboxHostDll 模块

**定义**: 专门为 Microsoft Office ClickToRun 设计的 Sandboxie 兼容性模块

**功能**: 通过 DLL 注入和 API Hook，为沙箱中的特殊账户进程提供有效的访问令牌

**技术**: DLL注入 + API Hook + 令牌替换

### 关键技术点

1. **DLL 注入** - Sandboxie 自动注入机制
2. **API Hook** - 拦截 OpenProcessToken API
3. **进程验证** - 只在 OfficeClickToRun.exe 中激活
4. **令牌分析** - 识别特殊账户（S-1-5-7, S-1-5-100-*）
5. **SID 匹配** - 通过登录会话 SID 匹配令牌
6. **令牌替换** - 用主机令牌替换沙箱令牌

### 核心函数

| 函数 | 作用 | 复杂度 |
|------|------|--------|
| `DllMain` | DLL入口点，验证进程 | ⭐⭐⭐ |
| `InjectDllMain` | 注入初始化入口 | ⭐ |
| `InitHook` | 设置API Hook | ⭐⭐ |
| `SboxHostDll_OpenProcessToken` | Hook函数，令牌替换 | ⭐⭐⭐⭐⭐ |
