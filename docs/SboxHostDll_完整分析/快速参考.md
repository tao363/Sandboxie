# SboxHostDll 快速参考指南

## 一分钟了解 SboxHostDll

### 是什么？
一个专门为 Office ClickToRun 设计的 Sandboxie 兼容性 DLL 模块。

### 做什么？
通过 Hook OpenProcessToken API，为沙箱中的 Office 进程提供有效的访问令牌。

### 怎么做？
1. 注入到 OfficeClickToRun.exe
2. Hook OpenProcessToken
3. 识别特殊账户令牌
4. 在主机进程中查找替代令牌
5. 替换并返回新令牌

---

## 核心代码速查

### 关键常量

```cpp
#define SBOX_HOST_DLL_LOADED L"Global\\SboxHostDllLoaded"
```

### 关键函数

```cpp
// 1. DLL入口 - 验证进程
BOOL APIENTRY DllMain(HMODULE hModule, DWORD ul_reason_for_call, LPVOID lpReserved);

// 2. 注入初始化
extern "C" __declspec(dllexport) void InjectDllMain(HINSTANCE hSbieDll, ULONG_PTR UnusedParameter);

// 3. 设置Hook
BOOLEAN InitHook(HINSTANCE hSbieDll);

// 4. Hook函数 - 令牌替换
BOOL SboxHostDll_OpenProcessToken(HANDLE ProcessHandle, DWORD DesiredAccess, PHANDLE phTokenOut);
```

### 特殊 SID

```cpp
S-1-5-7         // ANONYMOUS LOGON (匿名登录)
S-1-5-100-*     // Virtual Account (虚拟账户)
S-1-5-5-X-Y     // Logon SID (登录会话)
```

## 工作流程图

```
OfficeClickToRun.exe 启动
         ↓
Sandboxie 注入 SboxHostDll.dll
         ↓
DllMain 验证进程名
         ↓
InjectDllMain 初始化
         ↓
InitHook 设置 Hook
         ↓
应用调用 OpenProcessToken
         ↓
SboxHostDll_OpenProcessToken 拦截
         ↓
检查是否需要替换令牌
         ↓
查找主机进程中的匹配令牌
         ↓
返回替换后的令牌
```

## 常见问题

### Q: 为什么只针对 OfficeClickToRun.exe？
A: 因为该进程使用虚拟账户，在沙箱中令牌受限。

### Q: 如何判断是否需要替换令牌？
A: 检查用户 SID 是否为 S-1-5-7 或 S-1-5-100-*。

### Q: 如何确保令牌匹配？
A: 通过比较登录会话 SID（Logon SID）。

### Q: 性能影响如何？
A: 首次调用约 20-30ms，可通过缓存优化。
