## 💡 核心内容一览

### SboxHostDll 是什么？

一个专门为 **Microsoft Office ClickToRun** 设计的 Sandboxie 兼容性模块。

### 解决什么问题？

Office ClickToRun 使用**虚拟账户**运行，在沙箱环境中令牌受限，导致无法正常启动。

### 如何解决？

```
注入DLL → Hook API → 识别特殊账户 → 查找主机令牌 → 替换返回
```

### 关键技术

- 🔧 **DLL 注入**: Sandboxie 自动注入
- 🪝 **API Hook**: 拦截 OpenProcessToken
- 🎫 **令牌分析**: 识别虚拟账户（S-1-5-100-*）
- 🔍 **SID 匹配**: 通过登录会话 SID 匹配
- 🔄 **令牌替换**: 用主机令牌替换沙箱令牌
