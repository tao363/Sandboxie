## 函数概览

### 函数签名

```cpp
BOOL SboxHostDll_OpenProcessToken(
    HANDLE ProcessHandle,      // 目标进程句柄
    DWORD DesiredAccess,       // 请求的访问权限
    PHANDLE phTokenOut         // 输出令牌句柄的指针
)
```

这个函数是 `OpenProcessToken` API 的 Hook 函数，用于拦截和处理令牌请求。

## 完整源码分析

### 核心逻辑（带详细注释）

```cpp
BOOL SboxHostDll_OpenProcessToken(HANDLE ProcessHandle, DWORD DesiredAccess, PHANDLE phTokenOut)
{
    BOOL bRet = FALSE;
    HANDLE hToken = 0;
    std::wstring wsLogonSid;

    // 步骤1: 调用原始API获取令牌
    if (__sys_OpenProcessToken)
    {
        bRet = __sys_OpenProcessToken(ProcessHandle, DesiredAccess, 
                                       phTokenOut ? &hToken : phTokenOut);
    }

    // 步骤2: 检查是否需要处理
    if (bRet)
    {
        // 检查目标进程是否在沙箱中
        if (SbieApi_QueryProcessInfo((HANDLE)GetProcessId(ProcessHandle), 0) 
            & SBIE_FLAG_VALID_PROCESS)
        {
            BOOL bNeedAnotherValidToken = FALSE;
            ATL::CAccessToken token;
            ATL::CSid userSid;
            ATL::CSid logonSid;
            
            token.Attach(hToken);

            // 步骤3: 分析令牌的用户SID
            if(token.GetUser(&userSid))
            {
                // 检查是否为特殊账户
                if (lstrcmpi(userSid.Sid(), _T("S-1-5-7"))==0 || 
                    _wcsnicmp(userSid.Sid(), _T("S-1-5-100-"), 10)==0)
                {
                    if(token.GetLogonSid(&logonSid))
                    {
                        wsLogonSid = logonSid.Sid();
                        bNeedAnotherValidToken = TRUE;
                    }
                }
            }

            token.Detach();

            // 步骤4: 查找替代令牌
            if (bNeedAnotherValidToken)
            {
                HANDLE hAltToken = 0;
                DWORD aPid[1024], cbReturned, nPidCount;

                if (EnumProcesses(aPid, sizeof(aPid), &cbReturned))
                {
                    nPidCount = cbReturned / sizeof(DWORD);
                    
                    for (UINT i = 0; i < nPidCount; i++)
                    {
                        // 只处理主机进程（非沙箱进程）
                        if (!SbieApi_QueryProcessInfo((HANDLE)aPid[i], 0) 
                            & SBIE_FLAG_VALID_PROCESS)
                        {
                            HANDLE hProc = OpenProcess(PROCESS_ALL_ACCESS, TRUE, aPid[i]);
                            if (hProc)
                            {
                                if (__sys_OpenProcessToken(hProc, DesiredAccess, &hAltToken))
                                {
                                    ATL::CAccessToken altToken;
                                    altToken.Attach(hAltToken);

                                    if(altToken.GetLogonSid(&logonSid))
                                    {
                                        std::wstring wsAltLogonSid = logonSid.Sid();
                                        
                                        // 比较登录会话SID
                                        if (wsAltLogonSid == wsLogonSid)
                                        {
                                            altToken.Detach();
                                            CloseHandle(hProc);
                                            break;
                                        }
                                    }

                                    altToken.Detach();
                                    CloseHandle(hAltToken);
                                    hAltToken = 0;
                                }
                                CloseHandle(hProc);
                            }
                        }
                    }
                }

                // 步骤5: 替换令牌
                if (hAltToken)
                {
                    CloseHandle(hToken);
                    hToken = hAltToken;
                    bRet = TRUE;
                }
            }
        }

        if (phTokenOut)
            *phTokenOut = hToken;
    }

    return bRet;
}
```

## 算法流程详解

### 流程图

```
开始
  ↓
调用原始 OpenProcessToken
  ↓
成功？ ──否→ 返回 FALSE
  ↓是
检查进程是否在沙箱中
  ↓
在沙箱中？ ──否→ 返回原始令牌
  ↓是
获取用户 SID
  ↓
是特殊账户？ ──否→ 返回原始令牌
(S-1-5-7 或 S-1-5-100-*)
  ↓是
获取登录会话 SID
  ↓
枚举系统进程
  ↓
遍历每个进程
  ↓
是主机进程？ ──否→ 跳过
  ↓是
获取进程令牌
  ↓
比较登录会话 SID
  ↓
匹配？ ──否→ 继续下一个
  ↓是
替换令牌
  ↓
返回新令牌
```

## Windows令牌基础

### 访问令牌的组成

```
访问令牌 (Access Token)
├── 用户 SID - 标识用户身份
├── 组 SID 列表
│   ├── 登录会话 SID ⭐
│   └── 其他组
├── 权限列表
└── 其他属性
```

### 常用令牌访问权限

| 权限 | 值 | 说明 |
|------|-----|------|
| TOKEN_QUERY | 0x0008 | 查询令牌信息 |
| TOKEN_DUPLICATE | 0x0002 | 复制令牌 |
| TOKEN_ALL_ACCESS | 0xF01FF | 所有权限 |

## SID详解

### SID 格式

```
S-R-I-S-S-S-...

S: 前缀 "S"
R: 版本号 (通常是 1)
I: 颁发机构
S: 子权限 (可多个)
```

### 关键 SID

| SID | 名称 | 说明 |
|-----|------|------|
| `S-1-5-7` | ANONYMOUS LOGON | 匿名登录 ⭐ |
| `S-1-5-18` | SYSTEM | 系统账户 |
| `S-1-5-100-*` | Virtual Account | 虚拟账户 ⭐ |
| `S-1-5-5-X-Y` | Logon SID | 登录会话 ⭐ |

### 虚拟账户

**特点**:
- Windows 7+ 引入
- 用于服务账户
- 无密码，自动管理
- Office ClickToRun 使用此类账户

### 登录会话 SID

**作用**:
- 标识登录会话
- 用于匹配同一会话的令牌
- 本模块的核心匹配依据

## 令牌替换算法

### 算法目标

为沙箱中的特殊账户进程提供有效的主机令牌，同时保持登录会话一致性。

### 关键步骤

#### 1. 识别特殊账户

```cpp
if (lstrcmpi(userSid.Sid(), _T("S-1-5-7"))==0 ||          // 匿名登录
    _wcsnicmp(userSid.Sid(), _T("S-1-5-100-"), 10)==0)   // 虚拟账户
```

#### 2. 提取登录会话 SID

```cpp
token.GetLogonSid(&logonSid);
wsLogonSid = logonSid.Sid();  // 例如: "S-1-5-5-0-123456"
```

#### 3. 枚举并筛选主机进程

```cpp
EnumProcesses(aPid, sizeof(aPid), &cbReturned);

// 只处理非沙箱进程
if (!SbieApi_QueryProcessInfo((HANDLE)aPid[i], 0) & SBIE_FLAG_VALID_PROCESS)
```

#### 4. 匹配登录会话

```cpp
if (wsAltLogonSid == wsLogonSid)  // 找到匹配的令牌
```

#### 5. 替换令牌

```cpp
CloseHandle(hToken);
hToken = hAltToken;
```

### 算法复杂度

- **时间复杂度**: O(n)，n 为系统进程数
- **空间复杂度**: O(1)，固定大小数组

### 性能考虑

**典型场景**:
- 系统进程数: 100-200
- 搜索时间: 10-30ms
- 可通过缓存优化

## 总结

`SboxHostDll_OpenProcessToken` 函数通过以下机制实现令牌替换：

1. ✅ 拦截 OpenProcessToken 调用
2. ✅ 识别特殊账户令牌
3. ✅ 在主机进程中查找匹配令牌
4. ✅ 保持登录会话一致性
5. ✅ 透明替换令牌

这个设计确保了 Office ClickToRun 在沙箱环境中的正常运行。
