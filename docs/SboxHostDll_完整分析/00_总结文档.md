## 模块概述

**SboxHostDll** 是 Sandboxie 沙箱系统中的专用兼容性模块，专门解决 Microsoft Office ClickToRun 服务在沙箱环境中的访问令牌问题。

| **模块名称** | SboxHostDll.dll |
| **目标进程** | OfficeClickToRun.exe |
| **主要技术** | DLL注入 + API Hook + 令牌替换 |
| **代码行数** | ~395 行（纯代码 ~260 行） |
| **开发语言** | C++ (ATL) |
| **许可证** | GPL v3.0 |

### 1. DllMain - DLL入口点

**功能**: 验证目标进程，创建全局标识

**关键代码**:
```cpp
BOOL APIENTRY DllMain(HMODULE hModule, DWORD ul_reason_for_call, LPVOID lpReserved)
{
    switch (ul_reason_for_call)
    {
    case DLL_PROCESS_ATTACH:
        WCHAR wszDLLPath[MAX_PATH + 1];
        if (GetModuleFileName(GetModuleHandle(NULL), wszDLLPath, MAX_PATH))
        {
            if (wcsstr(wszDLLPath, L"OfficeClickToRun.exe"))
            {
                g_hInjectedGlobalNameObj = CreateMutex(NULL, FALSE, SBOX_HOST_DLL_LOADED);
                return TRUE;  // 允许加载
            }
            return FALSE;  // 拒绝加载
        }
        break;
        
    case DLL_PROCESS_DETACH:
        if (g_hInjectedGlobalNameObj)
            CloseHandle(g_hInjectedGlobalNameObj);
        break;
    }
    return TRUE;
}
```

**关键点**:
- ✅ 只在 OfficeClickToRun.exe 中加载
- ✅ 创建全局互斥体标识
- ✅ 非目标进程返回 FALSE 拒绝加载

### 2. InjectDllMain - 注入初始化

**功能**: Sandboxie 注入后的初始化入口

**代码**:
```cpp
extern "C" __declspec(dllexport) void InjectDllMain(HINSTANCE hSbieDll, ULONG_PTR UnusedParameter)
{
    InitHook(hSbieDll);
}
```

**特点**:
- 使用 C 链接规范（extern "C"）
- 导出函数，供 Sandboxie 调用
- 调用 InitHook 设置 Hook

### 3. InitHook - 设置API Hook

**功能**: 初始化 OpenProcessToken 的 Hook

**代码**:
```cpp
BOOLEAN InitHook(HINSTANCE hSbieDll)
{
    if (hSbieDll && !__sys_OpenProcessToken)
    {
        HMODULE module = GetModuleHandle(L"Advapi32.dll");
        void *OpenProcessToken = GetProcAddress(module, "OpenProcessToken");
        
        if (OpenProcessToken)
            SBIEDLL_HOOK(SboxHostDll_, OpenProcessToken);
    }
    return TRUE;
}
```

**关键点**:
- ✅ 防止重复 Hook
- ✅ 从 Advapi32.dll 获取函数地址
- ✅ 使用 SBIEDLL_HOOK 宏设置 Hook

### 4. SboxHostDll_OpenProcessToken - 核心Hook函数

**功能**: 拦截 OpenProcessToken 调用，替换特殊账户的令牌

**算法流程**:
```
1. 调用原始 OpenProcessToken 获取令牌
   ↓
2. 检查目标进程是否在沙箱中
   ↓
3. 分析令牌的用户 SID
   ↓
4. 判断是否为特殊账户 (S-1-5-7 或 S-1-5-100-*)
   ↓
5. 提取登录会话 SID
   ↓
6. 枚举系统进程，查找主机进程
   ↓
7. 比较登录会话 SID，找到匹配的令牌
   ↓
8. 替换并返回新令牌
```

**特殊账户**:
- `S-1-5-7`: ANONYMOUS LOGON（匿名登录）
- `S-1-5-100-*`: Virtual Account（虚拟账户）

**匹配依据**: 登录会话 SID（Logon SID）

## 关键技术点

### 1. DLL 注入

**方法**: Sandboxie 自动注入

**时机**: 目标进程启动时

**验证**: 检查进程名称，只在 OfficeClickToRun.exe 中加载

### 2. API Hook

**技术**: SBIEDLL_HOOK 宏（可能使用 IAT Hook 或 Inline Hook）

**目标**: OpenProcessToken (Advapi32.dll)

**效果**: 
```
Hook 前: 应用 → OpenProcessToken (系统)
Hook 后: 应用 → SboxHostDll_OpenProcessToken → __sys_OpenProcessToken (系统)
```

### 3. 令牌替换

**识别**: 检查用户 SID 是否为特殊账户

**查找**: 枚举主机进程，查找匹配的令牌

**匹配**: 比较登录会话 SID（Logon SID）

**替换**: 用主机令牌替换沙箱令牌

### 4. ATL 安全类

**CAccessToken**: 令牌操作的高级封装
```cpp
ATL::CAccessToken token;
token.Attach(hToken);           // 附加句柄
token.GetUser(&userSid);        // 获取用户 SID
token.GetLogonSid(&logonSid);   // 获取登录会话 SID
token.Detach();                 // 分离句柄
```

**CSid**: SID 操作的高级封装
```cpp
ATL::CSid sid;
LPCTSTR sidString = sid.Sid();  // 获取 SID 字符串
```

## 解决的问题

### 问题背景

Microsoft Office ClickToRun 使用虚拟账户或匿名登录账户运行服务，这些特殊账户的访问令牌在 Sandboxie 沙箱环境中受到限制，导致：

- ❌ Office 应用无法正常启动
- ❌ ClickToRun 服务无法访问必要的系统资源
- ❌ 文档打开失败或功能受限

### 解决方案

SboxHostDll 通过以下机制解决问题：

1. ✅ **拦截令牌请求**: Hook OpenProcessToken API
2. ✅ **识别特殊账户**: 检测虚拟账户和匿名登录令牌
3. ✅ **查找有效令牌**: 在主机进程中找到有效的替代令牌
4. ✅ **保持会话一致**: 通过 Logon SID 匹配确保会话一致
5. ✅ **透明替换**: 对应用程序完全透明

## 安全考虑

### 安全机制

1. ✅ **进程验证**: 只在目标进程中加载
2. ✅ **会话隔离**: 通过 Logon SID 确保会话一致
3. ✅ **权限检查**: 只替换特定类型的令牌
4. ✅ **资源管理**: 正确关闭句柄，防止泄漏

### 潜在风险

1. ⚠️ **全局互斥体**: 可能被恶意程序抢先创建
2. ⚠️ **进程名检查**: 使用子字符串匹配，可能误判
3. ⚠️ **性能开销**: 枚举所有进程可能影响性能
