## 📖 核心内容概览

### 模块功能

**SboxHostDll** 是一个专门为 Microsoft Office ClickToRun 设计的 Sandboxie 兼容性模块：

- 🎯 **目标进程**: OfficeClickToRun.exe
- 🔧 **核心技术**: DLL注入 + API Hook + 令牌替换
- 🎫 **处理对象**: 虚拟账户和匿名登录令牌
- ✅ **最终效果**: 确保 Office 在沙箱中正常运行

### 技术架构

```
注入 → 验证 → Hook → 拦截 → 分析 → 查找 → 替换 → 返回
```

### 关键技术

1. **DLL 注入**: Sandboxie 自动注入机制
2. **API Hook**: 拦截 OpenProcessToken 调用
3. **令牌分析**: 识别特殊账户（S-1-5-7, S-1-5-100-*）
4. **SID 匹配**: 通过登录会话 SID 匹配令牌
5. **令牌替换**: 用主机令牌替换沙箱令牌
