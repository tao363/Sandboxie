## 🎯 核心内容

### 1. 模块分析

**SboxHostDll** 是什么？
- 专门为 Office ClickToRun 设计的 Sandboxie 兼容性模块
- 通过 DLL 注入和 API Hook 技术工作
- 为沙箱中的特殊账户进程提供有效的访问令牌

**解决什么问题？**
- Office ClickToRun 使用虚拟账户运行
- 虚拟账户的令牌在沙箱中受限
- 导致 Office 应用无法正常启动

**如何解决？**
1. 注入到 OfficeClickToRun.exe
2. Hook OpenProcessToken API
3. 识别特殊账户令牌（S-1-5-7, S-1-5-100-*）
4. 在主机进程中查找匹配的令牌
5. 通过登录会话 SID 匹配
6. 替换并返回有效令牌

### 2. 技术架构

```
完整工作流程:
进程启动 → 注入DLL → 验证进程 → 初始化Hook → 
拦截API → 分析令牌 → 查找替代 → 替换返回
```

**关键技术**:
- DLL 注入
- API Hook (SBIEDLL_HOOK)
- 令牌分析 (ATL CAccessToken)
- SID 匹配 (登录会话 SID)
- 进程枚举 (EnumProcesses)

### 3. 核心函数

| 函数 | 作用 | 复杂度 |
|------|------|--------|
| `DllMain` | DLL入口，验证进程 | ⭐⭐⭐ |
| `InjectDllMain` | 注入初始化 | ⭐ |
| `InitHook` | 设置API Hook | ⭐⭐ |
| `SboxHostDll_OpenProcessToken` | 令牌替换 | ⭐⭐⭐⭐⭐ |

### 4. 关键 SID

```
S-1-5-7         ANONYMOUS LOGON (匿名登录)
S-1-5-100-*     Virtual Account (虚拟账户)
S-1-5-5-X-Y     Logon SID (登录会话)
```
