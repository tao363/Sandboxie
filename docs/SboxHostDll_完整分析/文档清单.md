## 🎯 核心知识点

### 关键概念
- DLL 注入
- API Hook
- 访问令牌（Access Token）
- 安全标识符（SID）
- 虚拟账户（Virtual Account）
- 登录会话 SID（Logon SID）

### 关键函数
- `DllMain` - DLL 入口点
- `InjectDllMain` - 注入初始化
- `InitHook` - 设置 Hook
- `SboxHostDll_OpenProcessToken` - 令牌替换

### 关键 SID
- `S-1-5-7` - ANONYMOUS LOGON
- `S-1-5-100-*` - Virtual Account
- `S-1-5-5-X-Y` - Logon SID
