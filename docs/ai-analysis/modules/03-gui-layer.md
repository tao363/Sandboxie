# 模块级分析：GUI 层 (SandMan.exe - Sandboxie Plus)

## 1. 模块概述

**核心职责**：提供现代化的图形用户界面，让用户能够直观地管理沙箱、监控进程、配置选项、查看日志和执行各种沙箱操作。

**模块边界**：
- **输入**：用户交互、SbieSvc 通知、系统事件、配置文件
- **输出**：沙箱管理操作、进程控制、文件恢复、配置修改

**模块路径**：`SandboxiePlus/SandMan/`

---

## 2. 核心组件

### 2.1 主要模块

| 模块 | 职责 |
|-----|------|
| SandMan.cpp | 主窗口控制器 |
| QSbieAPI | API 封装层 |
| Views | 视图组件（沙箱树、日志、文件） |
| Windows | 窗口组件（设置、选项、恢复） |
| Wizards | 向导组件（设置、新建沙箱） |
| Engine | 引擎层（脚本、沙箱引擎） |
| Helpers | 辅助工具 |
