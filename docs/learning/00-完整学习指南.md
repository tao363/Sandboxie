## 🎯 学习目标

通过本系列文档的学习，你将能够：

### 初级目标（1-2 周）
- ✅ 理解 Sandboxie 的整体架构和工作原理
- ✅ 了解三层架构的设计思想
- ✅ 掌握基本的 Windows 内核概念
- ✅ 能够阅读和理解简单的代码模块

### 中级目标（3-4 周）
- ✅ 深入理解各层的实现细节
- ✅ 掌握文件系统和注册表虚拟化原理
- ✅ 理解进程隔离和 Hook 技术
- ✅ 能够修改配置和添加简单功能

### 高级目标（5-8 周）
- ✅ 完全掌握核心隔离机制
- ✅ 能够添加新的 Hook 和功能
- ✅ 理解安全边界和攻击面
- ✅ 能够诊断和修复复杂问题
- ✅ 掌握 Windows 内核编程技能

## 🛠️ 所需技术栈

### 必备技能

#### 1. C/C++ 编程
- **重要性**：⭐⭐⭐⭐⭐
- **用途**：整个项目的主要语言
- **学习资源**：
  - 《C Primer Plus》
  - 《C++ Primer》
  - 《Effective C++》

#### 2. Windows API
- **重要性**：⭐⭐⭐⭐⭐
- **用途**：理解系统调用和 API
- **学习资源**：
  - MSDN 文档
  - 《Windows 程序设计》（Charles Petzold）
  - 《Windows via C/C++》（Jeffrey Richter）

#### 3. Windows 内核编程
- **重要性**：⭐⭐⭐⭐⭐
- **用途**：驱动层开发
- **学习资源**：
  - 《Windows 内核原理与实现》
  - 《Windows Internals》（7th Edition）
  - WDK 文档

#### 4. 汇编语言
- **重要性**：⭐⭐⭐⭐
- **用途**：Hook 实现、底层调试
- **学习资源**：
  - 《汇编语言》（王爽）
  - 《x64 汇编语言编程》

### 进阶技能

#### 5. Qt 框架
- **重要性**：⭐⭐⭐
- **用途**：GUI 开发
- **学习资源**：
  - Qt 官方文档
  - 《C++ GUI Programming with Qt》

#### 6. 逆向工程
- **重要性**：⭐⭐⭐
- **用途**：分析和调试
- **学习资源**：
  - 《逆向工程权威指南》
  - IDA Pro 教程
  - WinDbg 教程

#### 7. 系统安全
- **重要性**：⭐⭐⭐⭐
- **用途**：理解安全机制
- **学习资源**：
  - 《Windows 安全编程》
  - 《漏洞战争》

## 📊 项目统计

### 代码规模
- **总代码行数**：约 170,000 行
- **核心代码**：约 120,000 行
- **文件数量**：约 300+ 个
- **主要语言**：C (60%), C++ (35%), 其他 (5%)

### 模块分布
| 模块 | 代码行数 | 文件数 | 复杂度 |
|------|---------|--------|--------|
| 内核驱动 (SbieDrv) | ~50,000 | 60+ | 高 |
| 用户态 DLL (SbieDll) | ~40,000 | 50+ | 高 |
| 系统服务 (SbieSvc) | ~30,000 | 30+ | 中 |
| API 层 (QSbieAPI) | ~15,000 | 20+ | 中 |
| GUI 层 (SandMan) | ~25,000 | 40+ | 中 |
| 辅助工具 | ~10,000 | 100+ | 低 |
