# 其他子服务器详细分析

## 1. SbieIniServer - 配置管理服务器

### 1.1 概述
负责管理 Sandboxie 的配置文件（Sandboxie.ini），处理配置的读取、写入、重载等操作。

### 1.2 核心功能

**配置读取：**
- 解析 INI 文件格式
- 支持多级配置（全局、沙箱、程序）
- 缓存配置数据

**配置写入：**
- 验证配置有效性
- 原子性更新
- 备份旧配置

**配置重载：**
- 监控文件变化
- 通知驱动更新
- 刷新缓存

**权限管理：**
- 检查管理员权限
- 验证令牌
- 控制配置访问

### 1.3 消息类型
- `MSGID_SBIE_INI_GET_SETTING` - 获取配置项
- `MSGID_SBIE_INI_SET_SETTING` - 设置配置项
- `MSGID_SBIE_INI_RELOAD` - 重载配置
- `MSGID_SBIE_INI_GET_USER` - 获取用户信息

---

## 2. FileServer - 文件操作服务器

### 2.1 概述
处理沙箱进程的文件操作请求，实现文件重定向和访问控制。

### 2.2 核心功能

**路径解析：**
- 将沙箱路径映射到真实路径
- 处理符号链接
- 解析相对路径

**文件重定向：**
- 写时复制（Copy-on-Write）
- 虚拟文件系统
- 快照管理

**访问控制：**
- 检查文件权限
- 应用沙箱规则
- 记录访问日志

**特殊文件处理：**
- 系统文件保护
- 配置文件隔离
- 临时文件管理

### 2.3 消息类型
- `MSGID_FILE_OPEN` - 打开文件
- `MSGID_FILE_QUERY` - 查询文件信息
- `MSGID_FILE_SET` - 设置文件属性
- `MSGID_FILE_MIGRATE` - 迁移文件

---

## 3. ComServer - COM 组件服务器

### 3.1 概述
处理 COM 组件的跨沙箱调用，实现 COM 代理机制。

### 3.2 核心功能

**COM 代理：**
- 启动 COM 代理进程
- 管理代理生命周期
- 转发 COM 调用

**CLSID 管理：**
- 注册表重定向
- CLSID 映射
- 代理对象创建

**接口封送：**
- 参数序列化
- 跨进程传递
- 结果反序列化

**安全检查：**
- 验证 CLSID
- 检查权限
- 防止恶意调用

### 3.3 代理进程
- 命令行：`SbieSvc.exe SANDBOXIE_ComProxy`
- 每个沙箱一个代理进程
- 运行在沙箱外部

---

## 4. ServiceServer - Windows 服务代理

### 4.1 概述
处理沙箱进程对 Windows 服务的访问，实现服务调用代理。

### 4.2 核心功能

**服务枚举：**
- 列出可用服务
- 过滤敏感服务
- 返回服务信息

**服务控制：**
- 启动/停止服务
- 查询服务状态
- 配置服务参数

**UAC 代理：**
- 处理需要提权的操作
- 显示 UAC 提示
- 验证用户授权

**服务隔离：**
- 限制服务访问
- 虚拟服务状态
- 防止服务滥用

### 4.3 UAC 代理进程
- 命令行：`SbieSvc.exe SANDBOXIE_UacProxy`
- 以管理员权限运行
- 处理提权请求

## 14. 子服务器协作

### 14.1 消息路由
所有子服务器通过 PipeServer 注册和通信：
```
Client -> PipeServer -> SubServer -> Response -> PipeServer -> Client
```

### 14.2 共享资源
- 共享内存池（Pool）
- 共享配置缓存
- 共享日志系统

### 14.3 生命周期管理
- 随 PipeServer 启动
- 接收进程结束通知
- 清理资源

### 14.4 错误传播
- 统一错误码
- 错误日志记录
- 错误恢复机制
